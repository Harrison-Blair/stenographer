# V3 — fixed-count relabel resource probe

Ran on 2026-10-20 from the worktree root. Each probe used a fresh Python process and a synthetic input with 192-dimensional embeddings, three interleaved voices, 2.2-second phrases, and 2.3-second spacing. The embeddings used a shared component with pairwise voice-center similarity 0.75 and seeded Gaussian noise (`seed=95619`, standard deviation 0.01). The fixed-count runs requested three speakers. The default run omitted `speaker_count` and used the same 9,000-phrase input. Peak RSS includes Python and input data; it uses `ru_maxrss` converted from KiB to GiB. No audio or transcript text was used or saved.

| Fixed count, 3 | 2,000 | 0.061 s | 0.069 GiB | 3 |
| Fixed count, 3 | 9,000 | 0.717 s | 0.406 GiB | 3 |

The fixed-count run used less RSS and less time than the default run on the same generated input. The default result collapsed the three similar centers into one cluster at its threshold; this run compares resource use, not clustering quality. The dense fixed-count similarity matrix is 9,000 × 9,000 float32 values. The remaining merge and tree records grow linearly with phrase count.

The prior verifier's failed M2 probe in `VERIFIED.md` measured 11.72 GiB and 155.1 s for fixed count at 9,000 phrases. That probe used a different synthetic input. Do not compare its timing directly with this run.
