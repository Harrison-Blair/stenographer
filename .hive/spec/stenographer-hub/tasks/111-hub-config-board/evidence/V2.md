# V2 — Config visual captures

The Config screen captures use **150×45 cells**. Each pilot used fake services,
a temporary configuration, and no audio, model, `live`, or `run` process. The
captures select the ASR group. The latest after capture selects `beam_size`; its
config file has `beam_size = 5` and 40 synthetic hotwords. A draft edit changes
`idle_unload_seconds` to `4`, so the capture shows changed-value dots and
`1 unsaved change`.

The original before capture shows the screen at the original task base. The
V4-repair-before capture uses source commit `3d8e0e2`. The latest after SVG is the
direct output of `app.save_screenshot()`. For the original-before and latest-after PNG
conversions, I added `xml:space="preserve"` to a temporary SVG copy before
`rsvg-convert`. The saved SVGs omit that attribute, so the converter otherwise
drops leading terminal spaces and misplaces the value column. The compositor
text files record the unmodified pilot cells.

| State | Textual `app.save_screenshot()` SVG | Compositor text | SVG-rendered PNG |
| --- | --- | --- | --- |
| Before original task implementation | `before-config.svg` | `before-config.txt` | `before-config.png` |
| Before V4 repair | `before-repair-config.svg` | `before-repair-config.txt` | `before-repair-config.png` |
| After latest repair | `after-config.svg` | `after-config.txt` | `after-config.png` |

The final capture shows the legible `asr` panel title, aligned name/value
columns, the separate hotwords area with a width-limited preview ending in
`… 40 words`, one unsaved-change count, and the selected `beam_size` help with
the bench citation. The tests also check that an empty list shows `none` and a
short list appears in full without an ellipsis. See `visual-check.md` for the
element-by-element board comparison.
