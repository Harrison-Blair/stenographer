# V2 — output equivalence

Compared `relabel_system_lines` from the base revision (`origin/dev`, `6e80174`) with the new implementation. The baseline source was loaded from `git show origin/dev:src/stenographer/lib/live/relabel.py`. For each run, the comparison required exact equality of every `(speaker_id, label)` pair.

The seeded cases used 600 phrases each, 192-dimensional embeddings, four voice centers, five durations (0.45, 1.4, 2.2, 3.5, and 6.0 seconds), renamed labels, a minor voice, and short residue. Minor-voice phrases were at least 2.2 seconds. Threshold: 0.5.
