# V1 — Reset save path and targeted test

Setup reset is asynchronous. `HubApp.action_reset_config()` calls `run_worker()` with group `setup`. The worker awaits `asyncio.to_thread(save_defaults, path)`. `save_defaults()` calls `ConfigDocument.defaults(path).save(Config.defaults())`. The completion notification is sent only after the save returns.

The product orders the completion notification after the file save. The race was in the test: `pilot.pause()` did not await the setup worker. The test now captures the `setup` worker returned by `app.run_worker()` and awaits `worker.wait()` before reading the config. Product code is unchanged.
