# V3 — 200 targeted runs

Command: run the reset test 200 times in a shell loop. Each run used the worktree source through `PYTHONPATH=src`; the loop stopped and printed pytest output on the first failure.

```sh
set -e
log=$(mktemp)
trap 'rm -f "$log"' EXIT
for i in $(seq 1 200); do
  if ! PYTHONPATH=src /home/penguin/source/stenographer/.venv/bin/pytest -q \
    tests/cli/hub/test_setup_doctor.py::test_setup_defaults_replace_config_and_preserve_a_backup \
    >"$log" 2>&1; then
    printf 'FAILED on run %s/200\n' "$i"
    cat "$log"
    exit 1
  fi
done
printf 'PASS: 200/200 targeted test runs\n'
```

Result: `PASS: 200/200 targeted test runs`.
