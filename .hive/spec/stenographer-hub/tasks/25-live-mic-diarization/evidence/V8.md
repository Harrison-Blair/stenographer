# V8 — Hub renders: Live, rename, and Config, before and after

Design: no approved board (user waiver, 2026-10-21). These before/after renders
are the visual record. Each one is a pilot `save_screenshot()` SVG, its plain text,
and a PNG made with headless Firefox (`--window-size=1220,780`), all from
synthetic data only.

- **Before:** the base source `f5a0fc8`, exported with `git archive`.
- **After:** this branch, with `diarize_mic` on (the session is created with
  `diarize_mic=True`, and the Config file has `diarize_mic = true`).
- **Session:** a real `LiveSession` with the test fakes injected at its seams:
  a fake worker, recorder, segmenter, system capture, and a two-voice fake
  speaker tracker. There is no microphone or model. The session gets two mic
  phrases from two voices and one system phrase whose embedding equals mic
  voice 1.

## Plain-text state check (colour removed)

| Board element | state without colour | Result | Cause or decision |
| --- | --- | --- | --- |
| Mic speaker label, diarization on | words `Room 1`, `Room 2` | overridden | No board (waiver). Each room speaker has its own label text; both use the mic accent colour, so colour is never the only signal. |
| Mic speaker label, diarization off | word `You` | matches | Same as before (the before render). |
| System speaker label | words `Speaker 1` | matches | Unchanged: the system colour index stays the same because room IDs are listed after system IDs. |
| Transcript speaker count | words `3 speakers` | overridden | Now counts room speakers; no board (waiver). |
| Rename dialog title | words `Rename speaker` | overridden | Was `Rename system speaker`; the dialog now also lists room speakers. |
| Rename choices | words `Speaker 1`, `Room 1`, `Room 2` | overridden | Room speakers are added after the system speakers. |
| Config group list | word `live`, glyph `▶` for the selected group | overridden | New `live` group, after `asr` (`_GROUP_ORDER`). |
| `live.diarize_mic` value | word `on`, glyph `●` (differs from default) | matches | Same glyph rules as the other Config keys. |
