# V2 — Fallback to home when the sessions folder is absent; no folder created (requirements 2, 5)

Test: `test_files_browser_falls_back_to_home_without_recordings_folder`. `XDG_DATA_HOME` points to a tmp dir with no
`stenographer/sessions`. The test checks that the browser opens in the tmp home, that the title is `~`, and that the
output folder stays `<XDG_DATA_HOME>/stenographer/files`. It also checks that after the app has mounted and the Files section is shown, `sessions` still does not exist.

The unchanged code always opened home, so this test passed on it. It guards the fallback. To show that it can
fail, I broke the fallback on purpose by changing `self.directory = start if start.is_dir() else self.home` to
`self.directory = start`:


With the fix restored, the test passes (see V1 green run).
