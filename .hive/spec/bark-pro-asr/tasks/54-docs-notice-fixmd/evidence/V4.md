`scripts/check_site.sh` checks an assembled site. Assembled in scratch exactly as
`.github/workflows/pages.yml` does, then checked:

```
$ rm -rf _site; mkdir -p _site/assets; cp -r site/. _site/
$ cp src/stenographer/assets/icons/stenographer.png src/stenographer/assets/fonts/Caveat-wght.ttf src/stenographer/assets/fonts/Caveat-OFL.txt _site/assets/
$ scripts/check_site.sh _site; echo rc=$?
rc=0
```

Run on the raw `site/` folder it reports the three assets that only the workflow copies
in (`assets/Caveat-OFL.txt`, `assets/Caveat-wght.ttf`, `assets/stenographer.png`); that
is the same on dev before this change.
