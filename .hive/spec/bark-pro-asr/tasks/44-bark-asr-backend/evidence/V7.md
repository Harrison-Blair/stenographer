## Blocker for the gate: `tests/scripts/test_transcription_bench.py`

It imports `scripts/transcription_bench.py`, which imports
`scripts/transcription_study/decode.py`. That module is a copy of the Whisper
decode: it imports `_token_budget`, `_MAX_NEW_TOKENS`,
`_HALLUCINATION_SILENCE_SECONDS` and `_VAD_PARAMETERS` from the old backend,
builds `SegmentInfo(no_speech_prob=…)` and calls `_assemble(silence_threshold=…)`.
The spec has task B remove those, and task C delete `transcription_bench.py` and
its tests. The spec does not name `scripts/transcription_study/decode.py`, which
`asr_grid.py` (also deleted by C) and `transcription_bench.py` use.

Per the spec rule ("a task that finds a fact that contradicts this file stops
and tells the manager"), this is reported, not resolved here. Options:
1. Move into B the deletion of `scripts/transcription_bench.py`,
   `tests/scripts/test_transcription_bench.py` and
   `scripts/transcription_study/decode.py` (and maybe `asr_grid.py`).
2. Keep compatibility names in `lib/` until C (contradicts the Backend contract).
