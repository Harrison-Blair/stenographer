# V3 — no_speech_prob removed; one segment; token-to-word joining; probability (req 3)

- `SegmentInfo` has no `no_speech_prob` field
  (`test_segment_info_has_no_speech_probability`).
- `_assemble(segments, *, audio_seconds, vad_seconds)`: no `silence_threshold`;
  `_validate_output` unchanged and still called
  (`test_assemble_validates_word_density`, `test_model_rejects_a_runaway_decode`).
- `decode_segments(text, words)`: one `SegmentInfo` per decode spanning its words;
  none when the text is empty or only `<unk>`.
- `words_from_tokens`: a word starts at the SentencePiece marker (U+2581) or a
  leading space; a bare marker token starts the next word; `<unk>` is dropped;
  a token without letters or digits joins the previous word without widening
  its span (the task 26 bench rule). Span = timestamp + TDT duration (a point
  when sherpa gives no durations).
- `WordInfo.probability` = exp(mean token `ys_log_probs`) when the log-probs
  align with the tokens, else 1.0. Nothing gates on it.
