# V1 — sherpa-onnx backend behind the Model seam (req 1)

Base: dev `a115eea`. Code commit: `2d4f9de`.

`lib/transcribe/model.py` now builds
`sherpa_onnx.OfflineRecognizer.from_transducer(encoder=…encoder.int8.onnx,
decoder=…decoder.int8.onnx, joiner=…joiner.int8.onnx, tokens=…tokens.txt,
num_threads=cpu_threads, sample_rate=16000, decoding_method="greedy_search",
provider="cpu", model_type="nemo_transducer")` from
`bark_download.model_dir(data_dir)`. `cpu_threads` is `cfg.cpu_threads`, or
the existing `resolve_cpu_threads(0, physical_cores)` rule when 0.
`Model(cfg)`, `Model.transcribe(samples)` and `Model.close()` are unchanged for
callers; `recognizer=` and `data_dir=` are keyword-only test seams. A missing
model fails the load with `FileNotFoundError` naming
`stenographer model download --asr`.
