# V1: converter asset (requirement 1)

- File: `src/stenographer/assets/convert/bark_pro_to_sherpa.py`, from the task 26
  basis.
- Spec changes:
  - Fixed seeds: `random`, `numpy` and `torch` all use seed 0.
  - Fixed threads: torch 4; onnxruntime intra 4, inter 1.
  - Metadata comment "…@4b5c51e0…, CC-BY-4.0; int8 conversion by stenographer".
  - The graph check is an error: exit 4.
- Exit codes:
  - 0 ok.
  - 1 unexpected error.
  - 2 wrong arguments or a non-empty OUTPUT_DIR.
  - 3 a source file is missing or unreadable.
  - 4 graph check failed.
- The 2 and 3 checks run before the heavy imports, so the tests run the asset as a
  real subprocess in the test venv (`tests/lib/transcribe/test_bark_converter.py`).
- The fp32 intermediates go to `OUTPUT_DIR/.tmp/`, which a `finally` removes.
  Only the four int8 files remain.
- Graph check: fp32 max rel diff ≤ 1e-3. For int8, the mean cosine along the
  feature axis must be ≥ 0.8. The joiner token argmax agreement must be 1.0 for
  fp32 and ≥ 0.8 for int8. V7 gives the observed values and the reason for the
  rule.
- The asset defines no classes, to satisfy the repository rule that each class
  gets its own file (`tests/test_architecture.py`). The nn wrappers are
  `nn.Module()` instances with an instance `forward`, made by `module(...)` and
  `pointwise(...)`.
- A test checks that the asset imports only the stdlib and pinned packages, never
  stenographer. A test checks that its `PRO_REPO`, `PRO_REV` and `OUTPUTS` match
  the pins and `CONVERTED_FILES`.
- Allowlists: the `.gitignore` negations, the pyproject sdist exclude negations
  and wheel include, and the `packaging/stenographer.spec` comment (that spec
  already copies all of `assets/`). Check:
  - `git check-ignore -v` names the `!` negation lines 34-35.
  - `pip wheel --no-deps --no-build-isolation .` gives a wheel that contains
    `stenographer/assets/convert/bark_pro_to_sherpa.py` (14,104 B) and
    `constraints.txt` (910 B).
