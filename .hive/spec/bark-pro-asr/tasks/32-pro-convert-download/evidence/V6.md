# V6: failing-first tests (requirement 6)

Every new test was seen failing against the unfixed or deliberately broken code.

- Setup: the new tests against the HEAD `workflow.py` gave 13 failing guided
  tests.
- Pins: the pins test failed while `outputs` was empty and passes after the
  pin (V7).
- Free space: the 8 GiB test and the confirmation-text test failed with
  `6442450944 == 8 * 1024**3` and the "6 GiB" text, then passed after the change.

  target tests, and restored the file. Every source sha256 was the same after
  the run.
