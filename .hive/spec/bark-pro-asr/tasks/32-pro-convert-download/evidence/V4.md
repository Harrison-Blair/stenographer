# V4: `is_model_cached()` (requirement 4)

`bark_download.is_model_cached(data_dir=None, *, pins=BARK_PRO_PINS)`. With no
argument it uses the platform data dir.

It is True only when all of these hold:

- `bark-pro-int8/manifest.json` parses as schema 1, with a source revision and a
  non-empty files map of str to str.
- The revision equals the pinned revision.
- Every listed file exists as a regular file.
- No listed name contains `/` or is `.`, `..` or empty.

It does not hash the files.

Tests:

- parse accepts the schema-1 shape and rejects malformed manifests.
- matching model is cached.
- no hashing: the manifest hashes are all zeros and the files hold other bytes,
  and the model is still cached.
- another revision is not cached.
- a missing listed file is not cached.
- no dir or a corrupt manifest is not cached.
- a manifest cannot point outside the model dir.

Scope (manager decision 1): `lib/transcribe/download.py` and its callers
(transcribe, the Doctor capabilities, the Hub) do not change in this task. Task
B/C change them.
