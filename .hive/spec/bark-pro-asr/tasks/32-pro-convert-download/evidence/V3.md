# V3: `stenographer model download --asr` (requirement 3)

Code: `lib/transcribe/bark_download.py` `download_bark_pro()` (manager decision 1),
called by `cli/model/download/handler.py` `_download_asr()`.

Order (each step is a test; `test_steps_run_in_the_spec_order` records them all):

1. Present model with a matching manifest: return without a rebuild
   (`test_a_present_model_is_not_rebuilt`). The CLI prints "already present".
2. Venv check: `/usr/bin/python3 -I -c` with a find_spec probe for venv and
   ensurepip. No writes, no network. On failure the error has
   "Run `sudo apt install python3-venv`, then retry." and the CLI exits non-zero.
3. Free space on the filesystem of `models/asr/`: ≥ 8 GiB. The manager approved
   this on 2026-10-21 after the measured 6.91 GiB peak (V7); the brief and spec
   said 6 GiB. The check runs before any network call.
4. A temp `.build-*` dir under `models/asr/`; `/usr/bin/python3 -m venv`.
5. Lock sha256 check, then two pip installs with `--no-cache-dir
   --disable-pip-version-check -c constraints.txt`: torch from the CPU index,
   then the rest.
6. Source download: urllib over the pinned
   `https://huggingface.co/<repo>/resolve/<revision>/<path>` URLs, each with a
   sha256 check. The error names the failed file.
7. Converter: `<venv>/bin/python -I <asset> <source> <out>`. Each non-zero exit
   code maps to its own message.
8. Output sha256 check, fail closed. A missing file, an unpinned file or a
   mismatch stops the install and names the file.
9. NOTICE (the upstream text plus the modification line), LICENSE, then
   `manifest.json`.
10. Atomic install: a stale model dir moves into the build dir, then
    `os.replace(out, models/asr/bark-pro-int8)`.
11. `finally`: rmtree of the build dir (venv, BF16 source, partial output), on
    success and on failure, including KeyboardInterrupt.
12. The CLI prints the install path and the attribution line, then fetches only
    `silero_vad.onnx` through `download_live_models(data_dir, models=(silero,))`.

Subprocess and network are injected seams (`runner`, `fetch`). The runner is a
new platform contract, `lib/platform/command_runner.py` `CommandRunner` (`run`,
`run_quiet`). Its Linux implementation is
`lib/platform/linux/subprocess_command_runner.py`, reached through
`Platform.command_runner()`. The contract was needed because
`test_core_isolation` forbids `subprocess` in `lib/transcribe`. The
implementation has its own real-subprocess tests (exit code, quiet output, 127
when the command cannot start).

The real run is in V7.
