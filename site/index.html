Offline dictation for Wayland.

Press a hotkey, speak, get text at your cursor. Local Whisper, no accounts, no network. Audio and transcripts never leave the machine.

Linux x86_64 or AArch64, a Wayland session, and a systemd user manager. Downloads the latest release, verifies it against SHA256SUMS, and installs the user service. No Python or build tools needed.

How it works

  1. HotkeyRight Ctrl by default, in hybrid mode. Tap to latch, or hold, speak, and release. Plain hold and toggle modes are one setting away.
  2. MicrophonePortAudio capture, with a quiet-audio gate so an accidental press does not paste noise.
  3. Local transcriptionfaster-whisper runs on your CPU or GPU. The model is downloaded once, only when you ask.
  4. ClipboardThe transcript is copied first, and the paste only fires after the copy is confirmed and the key is physically released.
  5. Paste at the cursorA Shift+Insert chord through uinput. The text also stays on the clipboard.

Never leaves the machine

  • Audio, transcripts, configuration, device and model names.
  • Logs carry timings and counts, never transcript text.
  • The optional pill never receives transcript text or raw audio.
  • Analytics are local, numeric, exportable, and deletable.

The one network exception

At most once every 24 hours the daemon asks GitHub for the latest release tag. Metadata only, never a download, silent on failure. A desktop notification appears when a newer version exists.

[stenographer.feedback]
update_check = false

Install

  1. Check the essentials.

    A Wayland session, a systemd user manager, a PortAudio-backed microphone, read access to /dev/input/event* (usually the input group), write access to /dev/uinput, and wl-copy from wl-clipboard. stenographer doctor reports what is missing and how to fix it.

  2. Run the quick install, or build from source. 
    git clone https://github.com/Harrison-Blair/stenographer.git
cd stenographer
python3 -m venv .venv
.venv/bin/pip install -e ".[dev,build]"
scripts/install.sh --no-start
  3. Configure and download the model, about 1.5 GB, when the wizard offers it. 
    ~/.local/bin/stenographer setup --quick
  4. Start and dictate. 
    systemctl --user start stenographer.service

    Hold Right Ctrl, speak, release. Or tap to latch and tap again to stop.

Configuration lives at ~/.config/stenographer/config.toml. Saves through the CLI preserve your comments and unknown settings. Restart the service to apply changes.

CLI

stenographer runRun the daemon in the foreground.
stenographer transcribe FILE [--raw]Transcribe an audio file; optionally skip formatting.
stenographer model downloadDownload the configured ASR model into the local cache.
stenographer doctorCheck required capabilities and print fixes.
stenographer devicesList audio input devices.
stenographer setup [--quick | --default]Configure everything, only the common settings, or write the annotated defaults.
stenographer sounds [PACK]List, preview, or select a whole sound pack.
stenographer statsLifetime dictation totals; export as JSON or CSV.
stenographer completion {bash,zsh,fish}Print a native shell completion definition.

Add --help to any command for its full usage. Four sound packs ship: legacy, warm-desk, soft-electronic, and the default minimal-ui.
