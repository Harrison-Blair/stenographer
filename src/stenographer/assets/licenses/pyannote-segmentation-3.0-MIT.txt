pyannote segmentation 3.0 attribution

stenographer ships the pyannote segmentation 3.0 model as
`assets/models/pyannote-segmentation-3-0.onnx`. It finds where speech starts and
ends when a recording or file is saved. The file is the sherpa-onnx ONNX export
of the model (`sherpa-onnx-pyannote-segmentation-3-0`, `model.onnx`), sha256
220ad67ca923bef2fa91f2390c786097bf305bceb5e261d4af67b38e938e1079.

Upstream: https://huggingface.co/pyannote/segmentation-3.0
ONNX export: https://github.com/k2-fsa/sherpa-onnx
