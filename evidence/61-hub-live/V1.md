# V1 — Live panels and transcript views

Command:

```sh
.venv/bin/pytest -q tests/cli/hub/test_live_view.py
```

Result: `2 failed`. The hub showed its old recording placeholder, and its Live
keys did not call the fake session controls.

## Green

Command:

```sh
.venv/bin/pytest -q tests/cli/hub/test_live_view.py tests/cli/live/test_app.py
```

Result: `10 passed`. Pilot tests cover the mixed and split views, time order,
empty peer columns, panel status, source toggles, pause/resume, rename, and the
existing standalone Live behavior. Tests use fake services and a fake session.
They do not open an audio device.
