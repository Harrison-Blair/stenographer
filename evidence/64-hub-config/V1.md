# V1 — Config editing behavior

Date: 2026-10-20

Proves the Config screen, validated edits, undo, reset, save and backup, conflict handling, and invalid-file behavior.

## Red runs

Before implementation, the Config screen test failed because `HubApp` did not accept a config path:

```sh
PYTHONPATH=src /home/penguin/source/stenographer/.venv/bin/pytest tests/cli/hub/test_config.py -q
```

Result: `1 failed`; `HubApp.__init__()` rejected `config_path`.

The regression tests also failed when each behavior was temporarily disabled:

- Edit: `tests/cli/hub/test_config.py::test_edit_undo_and_reset_use_validated_config_values` kept beam size 1 instead of 3.
- Validation: `tests/cli/hub/test_config.py::test_invalid_edit_is_rejected_by_config_validation` accepted beam size 11 instead of keeping the valid value 1.
- Save: `tests/cli/hub/test_config.py::test_save_writes_validated_config_and_timestamped_backup` left the saved beam size at 1 and made no backup.
- Conflict: `tests/cli/hub/test_config.py::test_conflict_keeps_external_config_and_unsaved_draft` detected that a save without the loaded snapshot overwrote the external edit.
- Invalid file: `tests/cli/hub/test_config.py::test_invalid_config_is_read_only_and_shows_error_and_fix_path` failed when an invalid file was treated as defaults.
- Unsaved navigation: `tests/cli/hub/test_config.py::test_search_selects_a_key_and_unsaved_navigation_asks_for_discard` failed when the prompt was disabled.

Each temporary change was restored before the green run.
