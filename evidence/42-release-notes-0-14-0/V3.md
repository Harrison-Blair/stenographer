# V3 — common gate

The worktree did not have its own `.venv`. The gate used a temporary `.venv`
symlink to `/home/penguin/source/stenographer/.venv` and
`PYTHONPATH="$PWD/src"` so the tools loaded this worktree's source. The
symlink is temporary and will be removed after verification.

The first full test run found one stale expected version in
`tests/test_release_notes.py`: the changelog correctly reported `v0.14.0`, but
the test still expected `v0.13.2`. The user authorized changing that expected
version. The targeted test failed before the change and passed after it:

```text
Before: 1 failed — newest changelog version was v0.14.0; expected v0.13.2.
After:  1 passed in 0.02s
```
