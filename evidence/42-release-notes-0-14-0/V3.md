# V3 — common gate

The worktree did not have its own `.venv`. The gate used a temporary `.venv`
symlink to `/home/penguin/source/stenographer/.venv` and
`PYTHONPATH="$PWD/src"` so the tools loaded this worktree's source. The
symlink was removed after verification.

The full gate passed after the routing behavior was folded into the live
entry:

```text
$ .venv/bin/ruff check .
All checks passed!

$ .venv/bin/ruff format --check .
575 files already formatted

$ .venv/bin/pytest -m "not integration"
================ 2545 passed, 2 skipped, 6 deselected in 24.81s ================
```

The two skips are live-audio sample checks because the public sample clips are
absent. Six integration tests were deselected.
