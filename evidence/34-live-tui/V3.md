
Result: `1 failed`; the callback remained blocked while the UI called stop.

## Green run

```sh
PYTHONPATH=src .venv/bin/pytest -q tests/cli/live/test_app.py
```

Result: `3 passed`.

`App.run_test()` and `Pilot` verify pause, mic and system toggles, status display, transcript rendering, speaker rename updates, `q`, and Ctrl-C. Session stop runs off the UI thread so line callbacks can finish while the queue drains.
