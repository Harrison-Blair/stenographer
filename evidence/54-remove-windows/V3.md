The hotkey migration remains in `validation.py`. Its docstring no longer names
Windows. On Linux, load a CRLF configuration with the legacy Right Alt Agent
binding:

```sh
PYTHONPATH=src /home/penguin/source/stenographer/.venv/bin/python - <<'PY'
from stenographer.lib.config.models import Config

config = Config.loads('[stenographer.hotkey]\\r\\nbinding = "KEY_RIGHTALT"\\r\\n')
assert config.hotkey.binding == "KEY_RIGHTALT"
assert config.hotkey.general_binding == "KEY_RIGHTCTRL"
print("CRLF legacy hotkey config loads; Right Alt Agent binding is preserved")
PY
```
