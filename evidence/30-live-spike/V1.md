# V1: dependency install and runtime coexistence

Commands:

```sh
.venv/bin/pip install -e '.[dev]'          # existing dependencies baseline
 du -sb .venv                                # before new dependencies
.venv/bin/pip install -e '.[dev]'          # install updated project metadata
 du -sb .venv                                # after new dependencies
.venv/bin/pip download --no-deps --only-binary=:all: textual sherpa-onnx -d tmp/wheels
```

Observed `.venv` sizes were 545,570,771 bytes before and 601,501,513 bytes
after adding the two dependencies. Growth: 55,930,742 bytes (55.93 MB,
53.34 MiB). Installed versions and all direct and transitive wheel sizes are
in `bench.md`.

In one `.venv/bin/python` process, the imports succeeded and the process
created and retained these objects together: sherpa `VoiceActivityDetector`,
sherpa `SpeakerEmbeddingExtractor`, and faster-whisper `WhisperModel`. Output:

```text
imports: faster_whisper sherpa_onnx textual
live VAD: VoiceActivityDetector
speaker extractor: SpeakerEmbeddingExtractor
Whisper: WhisperModel
onnxruntime module imported: False
```

The three engines initialized without an ONNX Runtime conflict.
