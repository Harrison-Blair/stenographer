# V3: CPU benchmark

The final benchmark command, labelled WAV sources, all measurements, chosen
threshold, p95 gate, D6 cut assessment, and D9 PipeWire flag confirmation are
in `bench.md`.

The last run used the English-labelled sherpa speaker test clips and the
sherpa two-speaker release sample. `scripts/live_bench.py` emitted valid JSON;
`.venv/bin/python -m json.tool tmp/live-bench-final.json` completed
successfully. No live audio was captured.

Key results:

- VAD: one thread, 0.00223 RTF on the 16 s sample.
- Speaker clustering: 2 clusters, 0 over-splits, and 0 merges for every tested
  threshold from 0.30 through 0.70; selected 0.50 as the central tie-break.
- Embedding gate: p95 22.509 ms for 5 s with 2 threads, below 150 ms.
- Whisper: configured large-v3-turbo `int8`; 2 s, 5 s, and 15 s RTF values
  are 0.9191, 0.4308, and 0.1441.
- D9 command includes `--raw`. PipeWire 1.6.9 `pw-cat.1.md` says stdout uses
  an AU container without raw mode.
