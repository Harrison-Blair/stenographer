# V2: live model download and parser

Test-first records:

- Before the downloader existed, `.venv/bin/pytest -q
  tests/lib/live/test_download.py` failed during collection with
  `ModuleNotFoundError: No module named 'stenographer.lib.live'`.
- After the downloader implementation, the same command passed: `4 passed`.
  These tests use fake fetch functions. They verify hashes, skip an existing
  file with a valid hash, remove a partial file after fetch failure, and remove
  a bad-hash download without leaving a partial file.
- Before adding the parser flag,
  `.venv/bin/pytest -q
  tests/cli/model/download/test_handler.py::test_download_parser_accepts_the_live_model_flag`
  failed because argparse rejected `--live` as unrecognized. Afterward it
  passed: `1 passed`.
- The data-directory tests first failed to import `data_dir`; after the
  implementation `.venv/bin/pytest -q
  tests/lib/platform/linux/test_dirs.py` passed: `9 passed`.

Explicit download command, with XDG data and config paths isolated in the
worktree:

```sh
XDG_DATA_HOME="$PWD/tmp/xdg-data" XDG_CONFIG_HOME="$PWD/tmp/xdg-config" \
  .venv/bin/stenographer model download --live
```

The first run downloaded both files to
`tmp/xdg-data/stenographer/models/live/`. A second run reported both as
`already present`. SHA-256 values matched:

```text
silero_vad.onnx
9e2449e1087496d8d4caba907f23e0bd3f78d91fa552479bb9c23ac09cbb1fd6
nemo_en_titanet_small.onnx
ad4a1802485d8b34c722d2a9d04249662f2ece5d28a7a039063ca22f515a789e
```

`.venv/bin/stenographer model download --help` lists `--live`.
