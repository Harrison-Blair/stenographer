```sh

```

```text

```

Certifi is optional in the application. The build spec now includes it when it
is installed and otherwise uses the system trust store at runtime.

## Frozen command help

```sh
dist/stenographer/stenographer live --help
```

```text
usage: stenographer live [-h] [--mic] [--system] [--no-mic | --no-system]
                         [--device DEV]

options:
  -h, --help    show this help message and exit
  --mic         Enable microphone capture (default).
  --system      Enable system audio capture (default).
  --no-mic      Disable microphone capture.
  --no-system   Disable system audio capture.
  --device DEV  Use DEV as the microphone input device.
```

```sh
dist/stenographer/stenographer model download --help
```

```text
usage: stenographer model download [-h] [--asr] [--refine] [--live]

options:
  -h, --help  show this help message and exit
  --asr       Download only the speech-recognition model.
  --refine    Pull only the refine model through the configured Ollama host.
  --live      Download the live voice-activity and speaker models.
```

Neither help command started capture or downloaded models.
